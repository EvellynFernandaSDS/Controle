# 🔒 Projeto: Tela de Login (Dark Mode)

Este projeto é uma atividade avaliativa focada no desenvolvimento de uma aplicação web simples e no uso prático do Git e GitHub para controle de versão.

A aplicação consiste em uma página de login com tema escuro, utilizando HTML, CSS e JavaScript. O projeto foi estruturado seguindo um fluxo de versionamento com branches `main`, `develop`, `feature`, `hotfix` e `release`.

## ✨ Funcionalidades

* **Tema Escuro:** Interface de login moderna com paleta de cores escura.
* **Validação de Campos:** O JavaScript valida se os campos de usuário e senha estão vazios antes de tentar o login.
* **Feedback ao Usuário:**
    * Exibe "Preencha todos os campos!" se algum campo estiver vazio.
    * Exibe "Usuário ou senha incorretos." se os dados estiverem errados.
    * Exibe "Login realizado com sucesso!" com a cor verde se os dados estiverem corretos (usuário: `adm`, senha: `123`).
* **Páginas Adicionais:**
    * `dashboard.html`: Painel principal com menu e mensagem de boas-vindas.
    * `cadastro.html`: Formulário para cadastro de novos usuários.

## 💻 Tecnologias Utilizadas

* **HTML5**
* **CSS3**
* **JavaScript**
